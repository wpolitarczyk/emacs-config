Welcome to your personalized Emacs keybinding reference guide. This document groups all active shortcuts, prefixes, and Hydras by *task and intent* so you can quickly find the command you need.

* Quick Discovery Tools (When You Forget a Key)

Emacs has built-in discovery engines to help you find commands interactively without memorization:

| Discovery Method | Shortcut | Action |
|------------------+----------+-------------------------------------------------------------|
| *Which-Key*      | Any prefix | Press any prefix (e.g. ~C-c~, ~C-x~, ~s-l~) and pause 0.5s for a popup |
| *Embark Bindings*| ~C-h B~    | Searchable Vertico list of *all* active keys in the buffer  |
| *Helpful Key*    | ~C-h k~    | Press ~C-h k~ then any key to inspect its command & docs    |
| *Reference Guide*| ~C-c ?~    | Re-open this reference guide at any time                    |

* Master Hydra Index

Hydras group related multi-step commands into interactive transient menus. Once invoked, you can tap single letters without repeating prefix chords.

| Shortcut | Hydra Name | Purpose & Key Heads |
|----------+------------+-------------------------------------------------------------|
| ~C-c w~  | ~hydra-window~ | Window navigation (~h~/~j~/~k~/~l~), splits (~v~/~x~), delete (~d~/~o~), buffers (~b~), files (~f~) |
| ~C-x t h~ | ~hydra-tab-bar~ | Native tabs: new (~t~), close (~0~), switch (~l~/~j~), layout history (~[~/~]~) |
| ~C-c L~  | ~hydra-latex-tools~ | LaTeX: parse (~p~), reset (~r~), citations (~i~/~c~), outline (~o~), git-diff (~d~) |
| ~C-c Y~  | ~hydra-yas~ | Snippets: expand (~e~), insert (~i~), new (~n~), visit (~v~), reload (~R~) |
| ~C-c f h~ | ~hydra-flyspell~ | Spellcheck: next (~n~), correct (~c~), English (~e~), Polish (~p~), buffer (~b~) |
| ~C-c ! h~ | ~hydra-flycheck~ | Syntax errors: next (~n~), previous (~p~), explain (~e~), list all (~l~) |
| ~C-x v h~ | ~hydra-git-gutter~ | Git diffs: next (~j~), previous (~k~), stage (~s~), revert (~r~), popup (~p~) |
| ~C-c s~  | ~hydra-smartparens~ | Sexps: forward/back (~f~/~b~), barf (~h~/~l~), slurp (~H~/~L~), wrap (~w~), kill (~k~) |
| ~C-c d~  | ~hydra-describe~ | Help: bindings (~b~), function (~f~), variable (~v~), mode (~m~), key (~k~) |
| ~C-c H~  | ~hydra-apropos~ | Deep query: commands (~c~), variables (~v~), documentation (~d~), library (~l~) |
| ~<f3>~   | ~hydra-macro~ | Keyboard macros: record (~j~), end (~l~), call (~e~), counter (~n~), ring (~i~/~k~) |
