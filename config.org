* Package Management
:PROPERTIES:
:header-args: :tangle yes
:END:

This section establishes the package management infrastructure for Emacs. A reliable and declarative package manager ensures that all external libraries, themes, and language modes are automatically resolved, downloaded, and configured cleanly across different environments.

** Package Archives & MELPA

Emacs includes ~package.el~ as its standard package management client. By default, Emacs connects to GNU ELPA (and NonGNU ELPA in modern Emacs versions). To access the broader community ecosystem of Emacs packages, we register *Milkypostman's Emacs Lisp Package Archive* (MELPA).

- *Homepage*: [[https://melpa.org/][MELPA Official Site]]
- *Repository*: [[https://github.com/melpa/melpa][melpa/melpa on GitHub]]

#+begin_src emacs-lisp
  (require 'package)

  ;; Repository configuration - adding MELPA
  (add-to-list 'package-archives '("melpa" . "https://melpa.org/packages/") t)
#+end_src

** Declarative Configuration with use-package

~use-package~ provides a macro-based Domain-Specific Language (DSL) for declaring package configurations. It simplifies management by:
- Organizing package initialization (~:init~), configuration (~:config~), and keybindings (~:bind~).
- Enabling deferred (lazy) loading to optimize startup time.
- Handling conditional loading based on system types or installed tools.

Starting with Emacs 29.1, ~use-package~ is built directly into GNU Emacs core, so there is no need to install it from external repositories.

- *Upstream Repository*: [[https://github.com/jwiegley/use-package][jwiegley/use-package on GitHub]]
- *MELPA Page*: [[https://melpa.org/packages/use-package.html][use-package on MELPA]]
- *Manual*: [[https://www.gnu.org/software/emacs/manual/html_mono/use-package.html][GNU Emacs use-package Manual]]

#+begin_src emacs-lisp
  ;; Initialize built-in use-package (Emacs 29+)
  (require 'use-package)
#+end_src

** Automatic Package Installation

By default, ~use-package~ requires an explicit ~:ensure t~ directive on each block to trigger automatic package downloads. Setting ~use-package-always-ensure~ to ~t~ globally inverts this default so that any declared package is automatically installed from configured archives unless marked with ~:ensure nil~ (which we reserve for built-in Emacs features like ~dired~ or ~savehist~).

This makes bootstrapping this configuration on a fresh computer completely automatic.

#+begin_src emacs-lisp
  ;; Global setting ensuring that (use-package package-name) 
  ;; automatically downloads and installs it without needing ":ensure t" in every block.
  (setq use-package-always-ensure t)
#+end_src

** General Settings

Baseline configurations to improve everyday editing ergonomics, buffer synchronization, and session state.

*** Custom File & Local Private Configurations

By default, Emacs writes settings modified via the interactive Custom interface (~M-x customize~) directly to the bottom of ~init.el~. To prevent automatically generated Lisp from cluttering version-controlled configuration files, we redirect ~custom-file~ to a separate, untracked ~emacs-custom.el~.

Similarly, we dynamically load ~private.el~ if present. This allows storing private email credentials, local server paths, and machine-specific variables without exposing them to public version control.

#+begin_src emacs-lisp
  (setq custom-file (expand-file-name "emacs-custom.el" user-emacs-directory))
  (when (file-exists-p custom-file)
    (load custom-file))

  (let ((private-file (expand-file-name "private.el" user-emacs-directory)))
    (when (file-exists-p private-file)
      (load private-file)))
#+end_src

*** Modern Prompts (y/n)

Replaces full "yes or no" prompts with single-keystroke "y or n" confirmations. In modern Emacs (version 28+), ~use-short-answers~ is the native, standardized variable that replaces the legacy ~fset 'yes-or-no-p 'y-or-n-p~ alias.

#+begin_src emacs-lisp
  (setq use-short-answers t)
#+end_src

*** Parenthesis Highlighting & Auto-Closing

Efficient Lisp and text editing requires instant visual feedback on delimiter pairs.

- ~show-paren-mode~: Built-in mode that highlights the matching delimiter when the cursor is adjacent to an opening or closing parenthesis, bracket, or brace. Setting ~show-paren-style~ to ~'mixed~ highlights the matching paren if it is visible on screen, or highlights the entire enclosing expression if the matching delimiter is offscreen.
- ~electric-pair-mode~: Built-in minor mode that automatically inserts the matching closing delimiter (parentheses, quotes, brackets) whenever an opening delimiter is typed.

#+begin_src emacs-lisp
  ;; Highlight matching parentheses
  (setq show-paren-style 'mixed)
  (show-paren-mode 1)

  ;; Automatically insert closing delimiters
  (electric-pair-mode 1)
#+end_src

*** Spell Checking with Aspell

Configures Emacs' built-in ~ispell~ interface to use GNU Aspell as the underlying spell-checking engine instead of legacy Ispell. The default dictionary is set to American English.

- *Aspell Homepage*: [[http://aspell.net/][GNU Aspell]]

#+begin_src emacs-lisp
  (setq-default ispell-program-name "aspell")
  (setq ispell-dictionary "american")
#+end_src

*** Automatic Buffer Reversion

When editing files that are concurrently modified by external programs (such as Git checkouts, build scripts, or LaTeX compilers like ~latexmk~), ~global-auto-revert-mode~ ensures that open buffers update automatically when their disk contents change.

- ~global-auto-revert-non-file-buffers~: Extends auto-reversion to buffers that are not directly visiting files, such as Dired directory listings.
- ~auto-revert-verbose nil~: Silences notifications in the echo area so Emacs does not display an annoying message each time a background buffer refreshes.

#+begin_src emacs-lisp
  (global-auto-revert-mode t)
  (setq global-auto-revert-non-file-buffers t)
  ;; Suppress minibuffer notifications on every buffer refresh
  (setq auto-revert-verbose nil)
#+end_src

*** Interactive Configuration Shortcuts

Quick helper functions to reload or open the configuration without having to manually navigate the filesystem:

- ~reload-init~: Re-tangles ~config.org~ into ~config.el~ and evaluates the new configuration immediately.
- ~show-init-file~: Opens ~config.org~ directly in a buffer for fast editing.

#+begin_src emacs-lisp
  (defun reload-init ()
    "Update and reload configuration from the config.org file."
    (interactive)
    (org-babel-load-file (expand-file-name "config.org" user-emacs-directory)))

  (defun show-init-file ()
    "Open the configuration file for editing."
    (interactive)
    (find-file (expand-file-name "config.org" user-emacs-directory)))
#+end_src

*** Window Scrolling Behavior

Customizes the ~recenter-top-bottom~ command (bound to ~C-l~). By default, successive presses of ~C-l~ cycle the cursor position between the middle, top, and bottom of the active window. Setting ~recenter-positions~ to ~'(top middle bottom)~ prioritizes positioning the cursor near the top on the first invocation.

#+begin_src emacs-lisp
  (setq recenter-positions '(top middle bottom))
#+end_src

*** Asynchronous Backups & Auto-Save on Focus Loss

To prevent data loss without causing editor stutter on large files, we use ~async-backup~. It runs file backup operations in a separate asynchronous process so saving never blocks Emacs.

Additionally, an auto-save hook on ~focus-out-hook~ automatically saves modified buffers whenever the Emacs window loses OS focus (e.g., when switching to a browser or PDF reader).

- *Repository*: [[https://codeberg.org/contrapunctus/async-backup][contrapunctus/async-backup on Codeberg]]
- *MELPA Page*: [[https://melpa.org/packages/async-backup.html][async-backup on MELPA]]

#+begin_src emacs-lisp
  (use-package async-backup
    :hook (after-save . async-backup))

  ;; Autosave all modified buffers when Emacs loses focus
  (add-hook 'focus-out-hook (lambda () (save-some-buffers t)))
#+end_src

*** Soft Word Wrapping & Outline Navigation

- ~global-visual-line-mode~: Enables soft word wrapping at whitespace boundaries rather than truncating long lines or splitting words across rows.
- ~outline-minor-mode~: Enables heading folding and structural navigation in plain text buffers.

#+begin_src emacs-lisp

  (add-hook 'text-mode-hook #'outline-minor-mode)
#+end_src

*** Native Tab Bar & Window Configuration History

Emacs 27+ includes a native tab bar system (~tab-bar-mode~), where each tab represents a distinct window layout (comparable to workspaces or virtual desktops in other editors).

- ~tab-bar-history-mode~: Tracks the history of window configurations within each tab, allowing seamless undo and redo of window layout changes (splits, closures, and resizes) via ~M-[~ and ~M-]~.

#+begin_src emacs-lisp
  (tab-bar-mode 1)
  (tab-bar-history-mode 1)

  (global-set-key (kbd "M-[") 'tab-bar-history-back)
  (global-set-key (kbd "M-]") 'tab-bar-history-forward)
#+end_src

** Global Keybindings & Platform Tweaks

*** macOS Modifier Keys

When running GNU Emacs on macOS (Darwin/NextStep), the default modifier key mappings can conflict with standard macOS desktop conventions. This configuration maps:
- *Left Option*: mapped to ~alt~ (used for window navigation with windmove).
- *Right Option*: left unassigned (~none~) to permit entering special Polish diacritics / symbols via standard macOS keyboard layout.
- *Left Command*: mapped to ~meta~ (providing ergonomic ~M-~ access using the thumb).
- *Right Command*: mapped to ~super~ (~s-~).

#+begin_src emacs-lisp
  (when (eq system-type 'darwin)
    (setq ns-option-modifier 'alt
          ns-right-option-modifier 'none
          ns-command-modifier 'meta          ;; Left Command is Meta (M-)
          ns-right-command-modifier 'super)) ;; Right Command is Super (s-)
#+end_src

*** Global Text Scaling

** Background Emacs Server

Starting the built-in Emacs server allows external terminal commands (~emacsclient~) to quickly open files inside the existing Emacs instance without starting a new process.

Crucially, running the server is required for *SyncTeX backward-search* in PDF viewers (such as PDF-Tools or macOS Skim), allowing clicking on a location in a compiled PDF to jump directly to the corresponding source line in the LaTeX buffer.

- *Manual*: [[https://www.gnu.org/software/emacs/manual/html_node/emacs/Emacs-Server.html][GNU Emacs Server Manual]]

#+begin_src emacs-lisp
  (use-package server
    :ensure nil ; Built into Emacs
    :config
    (unless (server-running-p)
      (server-start)))
#+end_src

** Shell Environment Synchronization (exec-path-from-shell)

On macOS, graphical GUI applications launched from the Finder or Dock do not run inside an interactive login shell. Consequently, Emacs does not inherit shell environment variables such as ~$PATH~, ~$MANPATH~, or Homebrew paths (~/opt/homebrew/bin~).

~exec-path-from-shell~ queries the user's default shell (e.g., Zsh) upon startup and copies the environment variables into Emacs, ensuring external tools (compilers, git, python, ripgrep) are found seamlessly.

- *Repository*: [[https://github.com/purcell/exec-path-from-shell][purcell/exec-path-from-shell on GitHub]]
- *MELPA Page*: [[https://melpa.org/packages/exec-path-from-shell.html][exec-path-from-shell on MELPA]]

#+begin_src emacs-lisp
  (use-package exec-path-from-shell
    :config
    (when (or (memq window-system '(mac ns x))
              (daemonp))
      (exec-path-from-shell-initialize)))
#+end_src

#+end_src

  (defun my/list-config-hydras ()
    "Scan config.el for Hydras and their global keybindings."
    (interactive)
    (let ((config-path (expand-file-name "config.el" user-emacs-directory))
          (hydra-list '()))
      (if (not (file-exists-p config-path))
          (message "Config file not found: %s" config-path)
        (with-temp-buffer
          (insert-file-contents config-path)
          (goto-char (point-min))
          ;; Regexp to find (defhydra hydra-name ...)
          (while (re-search-forward "(defhydra \\([^ \t\n)]+\\)" nil t)
            (let* ((name (match-string 1))
                   (binding "No global binding found"))
              ;; Search specifically for global-set-key or :bind associated with this name
              (save-excursion
                (goto-char (point-min))
                (when (re-search-forward (concat "[\"']" name "/body[\"']") nil t)
                  (save-excursion
                    (backward-char (length name))
                    (when (re-search-backward "kbd \"\\([^\"]+\\)\"" nil t)
                      (setq binding (match-string 1))))))
              (push (cons name binding) hydra-list))))
        
        ;; Display the results
        (if (null hydra-list)
            (message "No Hydras found in config.el")
          (with-output-to-temp-buffer "*My Hydras*"
            (princ "Defined Hydras in config.el:\n")
            (princ "============================\n\n")
            (dolist (hydra (reverse hydra-list))
              (princ (format "%-25s Key: %s\n" (car hydra) (cdr hydra)))))))))
